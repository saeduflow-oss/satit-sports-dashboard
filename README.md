# แดชบอร์ดกีฬาสาธิตสามัคคี 2569

แดชบอร์ดประกาศผลการแข่งขันกีฬาแบบเรียลไทม์ เชื่อมต่อข้อมูลจาก Google Sheets
โทนสี **น้ำเงิน · ชมพู · ขาว · เทา** รองรับโหมดสว่าง/มืด และจอมือถือ

## โครงสร้างโปรเจกต์

```
กีฬาสาธิต/
├── package.json          # กำหนด dependency (express) และคำสั่งรัน
├── server.js             # เว็บเซิร์ฟเวอร์ Node.js + API /api/dashboard
├── data/
│   └── mock.json         # ข้อมูลตัวอย่าง (แทนที่ด้วย Google Sheets ภายหลัง)
└── public/               # ไฟล์ฝั่งหน้าเว็บทั้งหมด
    ├── index.html        # โครงหน้า (โครงสร้าง HTML)
    ├── css/
    │   └── styles.css    # ธีม โทนสี เลย์เอาต์ (แยกชัดเจน)
    ├── js/
    │   └── app.js        # ตรรกะ: โหลดข้อมูล, render, สลับวัน/ธีม
    └── assets/
        └── icons/        # ไอคอนกีฬา 15 ชนิด (ไฟล์ .svg แยกต่อกีฬา)
```

## วิธีรัน

```bash
npm install
npm start
```

แล้วเปิดเบราว์เซอร์ที่ **http://localhost:3000**

> เปิดผ่าน `http://` เท่านั้น (อย่าดับเบิลคลิกเปิดไฟล์ `index.html` ตรง ๆ
> เพราะ `fetch` จะถูกบล็อกโดย browser) — ถ้าจำเป็น หน้าเว็บมี fallback
> อ่าน `data/mock.json` ให้อัตโนมัติ

## กีฬาที่รองรับ (14 ชนิด)

กรีฑา · กอล์ฟ · เทนนิส · เทเบิลเทนนิส · บาสเกตบอล · บาสเกตบอล 3X3 ·
แบดมินตัน · เปตอง · ฟุตบอล · ลีลาศ · ว่ายน้ำ · หมากกระดาน · แฮนด์บอล ·
วอลเลย์บอล

กีฬาที่ไม่ได้ส่งแข่งอยู่ในลิสต์ `SPORTS_NOT_ENTERED` ใน `server.js` (ตอนนี้คือ **อีสปอร์ต**)
แถวของกีฬาในลิสต์นี้จะถูกตัดออกทั้งหน้าชนิดกีฬาและตารางแข่งขัน แม้ในชีตจะยังมีอยู่
ถ้าปีไหนกลับมาส่งแข่ง ให้เอาชื่อออกจากลิสต์นั้นและใส่ชื่อกลับเข้า `SPORT_IDS`

## ฟังก์ชันหลัก

- **หน้าแรก** — ภาพประจำวัน (สไลด์) + การ์ดสรุปของโรงเรียนเรา, การ์ดแมตช์ที่กำลังแข่ง,
  อันดับเหรียญ 8 อันดับแรก และประกาศผลล่าสุด
- **ผลการแข่งขันสด** — การ์ดสถานะ กำลังแข่ง / จบแล้ว พร้อมสกอร์
- **แท็บเลือกวัน** — สลับตารางแข่งขันและตัวเลขสดตามแต่ละวัน (วันนี้ / วันถัดไป)
- **ตารางแข่งขันรายวัน** — ไทม์ไลน์เรียงตามเวลา พร้อมไอคอนกีฬาและสถานที่
- **ตารางการแข่งขัน** (`schedule.html`) — ผังกำหนดการทั้งรายการ แยกพาเนลต่อวัน
  ไม่แบ่งหน้าและไม่ตัดข้อมูล ใช้เป็นผังอ้างอิง อ่านจากแท็บ **"ตารางการแข่งขัน"**
  ในชีต (`GID_SCHEDULE_PLAN` ใน `server.js`) คอลัมน์: วันที่ / กีฬา / ประเภท / เวลา /
  ทีม A / VS / ทีม B — แท็บนี้ไม่มีช่องผลกับสถานะ หน้านี้จึงไม่มีคอลัมน์ผล/สถานะ
  (ผลอยู่ที่หน้า "ตารางแข่งขัน" ซึ่งอ่านจากแท็บ "ผลการแข่งขันประจำวัน")
- **ตารางเหรียญ** — จัดอันดับอัตโนมัติ ไฮไลต์โรงเรียนเรา และลูกศรบอกทิศทางอันดับ
- **ชนิดกีฬาที่ส่งแข่ง** — การ์ดมาสคอตรายกีฬา แตะ/คลิกการ์ดเพื่อเปิดป๊อปอัป
  ที่บอกสถานะ จำนวนเหรียญ และรายการแข่งขันของกีฬานั้น (ปิดด้วย Esc / กากบาท / แตะนอกกล่อง)
- **สลับโหมดสว่าง/มืด** — จำค่าไว้ใน localStorage

## ภาพประจำวันบนหน้าแรก

แถบภาพบนสุดของหน้าแรกแสดง **เฉพาะภาพของวันที่กำลังแข่งอยู่ ในกีฬาของวันนั้น**
วันที่ถูกเลือกอัตโนมัติตามลำดับ: วันที่มีแมตช์สด → วันล่าสุดที่ประกาศผลแล้ว → วันแรกของรายการ
ถ้าวันนั้นยังไม่มีภาพ หน้าเว็บจะขึ้นข้อความบอกตรง ๆ ไม่ดึงภาพของวันอื่นมาแสดงแทน

ข้อมูลภาพอยู่ในฟิลด์ `photos` ของ API (ดูตัวอย่างใน `data/mock.json`):

```json
{ "id": "d1-football", "dayId": 1, "sportId": "football", "time": "10:30",
  "caption": "ฟุตบอลชาย รอบคัดเลือก สาย A", "venue": "สนามฟุตบอล",
  "credit": "ฝ่ายประชาสัมพันธ์", "src": "assets/photos/day1-football.svg" }
```

**วิธีต่อกับชีตจริง** — สร้างแท็บใหม่ในชีตเดิม คอลัมน์เรียงตามนี้

| วันที่ | กีฬา | เวลา | คำบรรยาย | สถานที่ | ลิงก์รูป | เครดิต |
|---|---|---|---|---|---|---|

แล้วใส่ `gid` ของแท็บนั้นที่ค่า `GID_PHOTOS` ใน `server.js` (ค่าว่าง = ยังไม่เปิดใช้)
ลิงก์แชร์จาก Google Drive ใส่ได้เลย เซิร์ฟเวอร์แปลงเป็นลิงก์รูปตรงให้เอง
วันที่ในแท็บนี้ต้องตรงกับวันในตารางแข่งขัน ไม่งั้นภาพนั้นจะถูกข้าม
ถ้าอ่านแท็บนี้ไม่สำเร็จ ส่วนอื่นของแดชบอร์ดยังทำงานตามปกติ

> ไฟล์ใน `public/assets/photos/` เป็นภาพตัวอย่างสำหรับข้อมูล mock เท่านั้น
> เมื่อมีภาพถ่ายจริงแล้วลบทิ้งได้

## เปลี่ยนไอคอนเป็นรูปภาพจริง (ในอนาคต)

ตอนนี้ไอคอนแต่ละกีฬาคือไฟล์ `public/assets/icons/<id>.svg` แสดงผ่าน CSS mask
(รับสีจากธีมอัตโนมัติ) — เมื่อมีรูปจริง มี 2 ทางเลือก:

1. แทนไฟล์ `.svg` ด้วยภาพเวกเตอร์ใหม่ (ใช้ mask ต่อได้ทันที) หรือ
2. ใช้ภาพถ่าย (`.png/.jpg/.webp`) → ใน `styles.css` เปลี่ยนคลาส `.sport-ic`
   จาก `mask` เป็น `background-image` และวางไฟล์ในโฟลเดอร์เดิม

รหัสกีฬา (`id`) ที่ใช้ตั้งชื่อไฟล์: `athletics, golf, tennis, tabletennis,
basketball, basketball3x3, badminton, petanque, football, dancesport,
swimming, boardgame, handball, volleyball`

## ต่อ Google Sheets จริง

แก้เฉพาะฟังก์ชัน `loadData()` ใน `server.js` (มีคอมเมนต์แนะนำ 2 วิธีไว้ในไฟล์):

- **วิธี A — Google Sheets API v4** (`npm i googleapis` + Service Account)
- **วิธี B — Apps Script Web App** (เผยแพร่ชีตเป็น JSON endpoint แล้ว fetch)

ขอเพียงคืน object ที่มี schema ตรงกับ `data/mock.json` — หน้าเว็บทำงานต่อได้
ทันทีโดยไม่ต้องแก้ frontend
